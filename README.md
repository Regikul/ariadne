# Ariadne

Ariadne — реализация на Erlang модели timely dataflow, формализованной
Мартином Абади и Майклом Айзардом в статье
[*Timely Dataflow: A Model*](okf/references/papers/timely-dataflow-a-model.md).
Оригинал статьи также хранится в репозитории в формате
[PDF](okf/references/papers/timely-dataflow-a-model.pdf).

Цель проекта — перенести семантику модели в исполняемую систему: ориентированный
граф с состоянием в узлах, сообщениями с виртуальным временем, очередями рёбер,
запросами уведомлений и отслеживанием прогресса через отношение
`could-result-in`. Конкретные API и OTP-архитектура Ariadne являются проектными
решениями поверх этой модели; проект не ставит целью воспроизвести архитектуру
Naiad.

## Текущий архитектурный рубеж

Первая версия исполняет весь граф внутри одного Erlang-процесса. Этот процесс
владеет состояниями всех узлов, очередями всех рёбер, запросами уведомлений и
состоянием прогресса. Обработка одного сообщения или уведомления является одним
атомарным переходом состояния графа.

После того как однопроцессная реализация станет корректным и тестируемым
эталоном, узлы и рёбра можно будет распределять между несколькими процессами.
Такое масштабирование не должно менять наблюдаемую семантику графа: порядок на
ребре, результаты операторов и момент допустимости уведомлений должны
сохраниться.

Проектные решения ведутся в [базе знаний OKF](okf/index.md). Первый документ
определяет [DSL описания графа](okf/design/graph-dsl.md).
